# docs/

Documentación transversal del monorepo que no pertenece a un proyecto concreto.

- `Modelo de datos VirGo.md` vive en la raíz porque lo comparten API y Móvil.
- Los diseños exportados de Figma pueden ir en `docs/design/` como PNG o PDF.
- No guardar secretos, tokens ni datos personales.
- La documentación de cada proyecto vive en su propia carpeta (`VirGo-API/`, `VirGo-Movil/`).
