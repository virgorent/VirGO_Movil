# docs/

Documentación transversal del monorepo que no pertenece a un proyecto concreto.

- El modelo de datos y la documentación del backend están en [`virgorent/virGO_App`](https://github.com/virgorent/virGO_App).
- Los diseños exportados de Figma pueden ir en `docs/design/` como PNG o PDF.
- No guardar secretos, tokens ni datos personales.
- La documentación de cada proyecto vive en su propia carpeta (`VirGo-Movil/`).
- [`frontend/MAPA-SPECS.md`](frontend/MAPA-SPECS.md): specs de Móvil, por flujo.
